This release adds MySQL and MariaDB support, improves internationalization, and includes various bug fixes and UI improvements.

---

## MySQL & MariaDB Support

**Connect to MySQL and MariaDB** — Seaquel now includes a full database adapter for MySQL and MariaDB. Browse schemas, inspect columns with foreign key references, view indexes, and run EXPLAIN queries — all the features you already know from PostgreSQL and SQLite, now available for MySQL-compatible databases.

---

## Internationalization

**Broader i18n Coverage** — The visual query builder and sample query strings are now fully internationalized, with proper plural forms for sidebar table counts. This continues our effort to make Seaquel accessible in more languages.

---

## Improvements

- The update notification toast now links directly to the relevant release notes
- Moved header tabs into the content area below the sidebar for a cleaner layout
- Removed unnecessary left-padding in the header when loaded in the browser
- Hidden the AI assistant button on the learn page

---

## Bug Fixes

- Fixed null safety issues in the table viewer when switching between schema tabs
- Fixed macOS entitlement issues
